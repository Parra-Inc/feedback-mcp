# Show HN title

Format: `Show HN: [Name] – [plain one-line description]`. No superlatives. dang won't
need to touch it.

## Recommended

```
Show HN: Feedback MCP – Self-hosted feedback collection with a built-in MCP server
```

Why this one: states exactly what it is, and "built-in MCP server" is the hook that
makes an HN reader click instead of scroll. Nothing to neutralize.

## Alternates

```
Show HN: Feedback MCP – Collect user feedback, read it back over MCP (no dashboard)
```
Leads with the contrarian "no dashboard" angle. Strong if you want the discussion to be
about the design bet.

```
Show HN: Feedback MCP – One endpoint in, an MCP server out, your own database
```
Most concrete on the architecture. Good if you expect a systems-minded crowd.

```
Show HN: Feedback MCP – Open-source feedback backend you query by asking Claude
```
Warmest framing; "query by asking Claude" is the demo in six words.

## Notes

- Use the en-dash-free `–`? HN convention is a hyphen/dash after the name. HN renders a
  plain `-` fine; the examples above use `–` only because that's HN's house style in the
  title slot. Either reads correctly.
- Do **not** add "🚀", "amazing," "the best," or a version number. All of it lowers trust
  here.
- After posting, the URL should point to the **GitHub repo**
  (`github.com/Parra-Inc/feedback-mcp`), not the marketing site. HN clicks want code.

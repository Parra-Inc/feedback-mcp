# Hacker News launch (primary)

The primary launch for Feedback MCP. It's a self-hosted, open-source developer tool with
a novel angle (no dashboard; your AI reads feedback over MCP). Exactly HN's wheelhouse.

> HN's readiness bar is the highest of any platform: no working demo, no launch. The repo
> and the live one-pager both clear it.

## Files

| File | What it's for |
|------|---------------|
| [`title.md`](title.md) | The `Show HN:` title + 3 alternates |
| [`first-comment.md`](first-comment.md) | Paste-ready top-level comment, technical-substance-first |
| [`launch-day.md`](launch-day.md) | Hour-by-hour timeline (Pacific) + comment-handling table |
| [`checklist.md`](checklist.md) | Pre-launch gate as tickable items |

## The 60-second version

1. **When:** Tue/Wed/Thu, ~7:00 AM PT.
2. **What to post:** the `Show HN:` title from `title.md`, URL = the **GitHub repo**.
3. **Immediately:** paste the first comment as a top-level reply.
4. **Then:** answer every comment for 3 hours. That's the launch.
5. **Never:** ask for upvotes. Anywhere. Ever.

## The one thing that matters most

Being present and non-defensive in the comments for the first two hours. Feedback MCP's
most-likely top comment is "why no dashboard?", and that's not a weakness to defend, it's
the core design bet to explain calmly. The whole thread is watching how you answer it.

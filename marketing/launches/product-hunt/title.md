# Product Hunt name + tagline

Product Hunt gives you a **name**, a **tagline** (≤60 chars, shown under the name), and a
**topics** list. Benefit-forward but not hypey.

## Name

```
Feedback MCP
```

## Tagline (recommended)

```
Collect user feedback from any app, analyze it with Claude
```
58 characters. This is the established brand line and it works: concrete, benefit-first,
names the AI payoff. Reuses the OG/banner copy so the click feels continuous.

## Description (the longer field under the gallery)

```
Feedback MCP is a free, open-source, self-hosted service for collecting user feedback and
analyzing it with AI.

Your apps POST to one endpoint. You read the feedback back through a built-in MCP server,
so you (and Claude) can just ask: "summarize this week's bug reports," "what are iOS users
asking for most." There's intentionally no dashboard: your AI assistant is the dashboard.

• One endpoint in: POST from iOS, Android, web, or any backend
• MCP out: list, search, and stat your feedback from claude.ai, Claude Desktop, or Claude Code
• Forms as config: declarative JSON, validated with Zod, editable by humans or LLMs
• Your database: Postgres, SQLite, or Cloudflare D1, chosen with one env var
• Slack cross-posting: optional, every submission to your team channel
• MIT licensed, deploy in one click to Render, Vercel, Cloudflare Workers, or any Docker host
```
